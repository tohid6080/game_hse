# چک‌لیست آزمون روی دستگاه

همه‌ی بخش‌هایی که در این محیط (Chromium، بدون Android SDK) نمی‌شد اجرا کرد، اینجا یکجا و قابل‌اجرا هستند. هر ردیف را اجرا کنید و ✓ یا ✗ بزنید؛ برای ✗ مدل گوشی، نسخه‌ی Android و شرح کوتاه بنویسید.

**آماده‌سازی:** یک APK debug یا release ([`RELEASE.md`](RELEASE.md))، گوشی با «USB debugging» یا فایل APK. بهتر است دو گوشی داشته باشید: یک گوشی جدید (Android ۱۴+) و یک گوشی قدیمی/ضعیف (Android ۷–۹، ۲ GB RAM یا کمتر).

## بعد از آزمون

- ✗ها را با مدل و نسخه گزارش کنید.
- ردیف‌های A6 و H2 تصمیم **حداقل نسخه‌ی پشتیبانی‌شده** را می‌سازند؛ اگر WebView بسیار قدیمی اجرا نشد، `minSdk` یا هدف `build.target` را باید بازنگری کرد.
- اگر A2 و B1 هر دو سبز بود، می‌توان CSP را سخت‌تر کرد (`connect-src 'none'`، یادداشت در `vite.config.ts`).
