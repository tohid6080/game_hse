# صحنه‌های «خطر را پیدا کن»

این سند می‌گوید یک صحنه از چه ساخته می‌شود، چطور اضافه می‌شود و چه چیزی در آن به‌صورت خودکار آزموده می‌شود. فهرست خطرهای پیشنهادی برای ساخت تصویر در `SCENE-BRIEFS.md` است.

## یک صحنه چیست

| بخش | جا | نکته |
|---|---|---|
| تصویر | `src/content/scenes/<image>.webp` | فقط WebP، همراه باندل (هیچ‌چیز از شبکه نمی‌آید) |
| متن و نقطه‌ها | `src/content/packs/<locale>/hazard.json` | هر زبان بسته‌ی خودش را دارد؛ شناسه‌ها در همه‌ی زبان‌ها یکی است |
| نمایش | `src/games/hazard/` | `PanZoomImage` (بزرگ‌نمایی و کشیدن)، `HazardMarkers`، `HazardPlay` |
| منطق | `src/games/hazard/engine.ts` و `geometry.ts` | خالص و تست‌شده |

### قالب JSON (هر صحنه)

```jsonc
{
  "id": "warehouse-01",              // کوچک، عدد، "." و "-"؛ هرگز عوض نمی‌شود (در تاریخچه‌ی بازیکن ذخیره می‌شود)
  "reviewStatus": "draft",           // draft | reviewed (reviewed یعنی هر خطر دست‌کم یک مرجع دارد)
  "industries": ["general"],         // بازیکن «عمومی» همه‌چیز را می‌بیند؛ بقیه عمومی + صنعت خودشان
  "title": "…", "description": "…",
  "image": "warehouse-01",           // نام فایل بدون پسوند
  "imageAlt": "…",                   // توضیح تصویر برای صفحه‌خوان
  "width": 1600, "height": 2000,     // اندازه‌ی واقعی فایل؛ تست مقایسه می‌کند
  "hazards": [ /* ۳ تا ۱۵ خطر */ ]
}
```

### قالب یک خطر

```jsonc
{
  "id": "warehouse-01.forklift",     // باید با شناسه‌ی صحنه + "." شروع شود
  "difficulty": 1,                   // ۱ آشکار · ۲ نیازمند دقت · ۳ ریز یا نیازمند دانش
  "topic": "hazard-identification",  // یکی از موضوع‌های HSE؛ به محور رادار وصل می‌شود
  "x": 0.318, "y": 0.482,            // مرکز، کسری از عرض و ارتفاع تصویر (۰ تا ۱)
  "radius": 0.06,                    // شعاع، کسری از «عرض» تصویر (دایره روی هر نسبتی گرد می‌ماند)
  "title": "…", "explanation": "…",
  "likelihood": 3, "severity": 4,    // ارزیابی کارشناس برای ریسک بدون کنترل (۱ تا ۵)
  "control": { "text": "…", "level": "engineering" },   // elimination | substitution | engineering | administrative | ppe
  "references": []
}
```

نقطه‌ها **نرمال‌شده**‌اند: با عوض‌کردن تصویر با وضوح بالاتر (همان نسبت) هیچ نقطه‌ای جابه‌جا نمی‌شود.

## قواعد تصویر

- **نسبت ۴:۵ عمودی** (مثلاً ۱۶۰۰×۲۰۰۰). روی گوشی عمودی، عکس افقی ریز می‌شود.
- **دست‌کم ۱۶۰۰ پیکسل عرض** تا بعد از ۲× یا ۳× بزرگ‌نمایی هنوز واضح باشد (بیشینه‌ی بزرگ‌نمایی ۴ برابر است).
- **WebP، حدود ۳۰۰ تا ۴۰۰ کیلوبایت**، هرگز بیش از ۶۰۰ کیلوبایت (تست رد می‌کند).
- بدون متن، لوگو، واترمارک و چهره‌ی نزدیک. تصویر خودش نباید «جواب» را نوشته باشد.
- حقوق استفاده از تصویر (به‌ویژه تصویر ساخته‌شده با هوش مصنوعی) به عهده‌ی صاحب محصول است.

## افزودن یک صحنه

1. تصویر را با نام `src/content/scenes/<id>.webp` بگذار.
2. خطرها را از روی **آنچه در تصویر دیده می‌شود** بنویس. تصویر مرجع است و فهرست تابع آن؛ اگر مولد تصویر موردی را نساخت، همان را از فهرست حذف یا جایگزین کن.
3. مختصات را بگذار: یا در ویرایشگر (پایین) یا با فرستادن تصویر برای من تا با همان ابزار روی آن علامت بگذارم.
4. صحنه را به `hazard.json` اضافه کن و `npm run check` را بزن.

### ویرایشگر مختصات (فقط توسعه)

```bash
npm run dev      # سپس: http://localhost:5173/#/dev/hazard-editor?scene=<id>
```

یک خطر را از فهرست انتخاب کن، روی تصویر بزن تا مرکزش بیاید، با لغزنده شعاعش را تنظیم کن و JSON را کپی کن. این مسیر فقط زمانی ثبت می‌شود که `import.meta.env.DEV` درست باشد؛ در build نهایی نه مسیرش هست نه کدش (E2E و جست‌وجوی `dist` این را بررسی می‌کنند). ویرایشگر چیزی ذخیره نمی‌کند.

## آنچه به‌صورت خودکار آزموده می‌شود

- JSON با schema می‌خواند و `parse(pack) == raw` است (بدون مقدار پیش‌فرض).
- هر صحنه تصویر دارد و اندازه‌ی اعلام‌شده همان اندازه‌ی سرآیند فایل است؛ هر فایل کمتر از ۶۰۰KB است.
- شناسه‌ی خطرها یکتا است و با شناسه‌ی صحنه شروع می‌شود؛ نقطه‌ای در میان تصویر قرار دارد و هیچ خطری زیر دیگری پنهان نمی‌شود.
- صحنه‌ی `reviewed` بدون مرجع رد می‌شود.
- هر مرکز خطر خودش را پیدا می‌کند، و کل دور (لمس اشتباه، راهنما، پایان، امتیاز) با تست واحد و E2E واقعی بررسی می‌شود.

## قواعد بازی (ثابت‌ها در `engine.ts` و `domain/`)

- لمس جای بی‌خطر یک لایه‌ی سپر می‌شکند؛ سه اشتباه دور را تمام می‌کند.
- راهنما حداکثر ۳ بار؛ دایره‌ی خط‌چینِ بزرگ‌تر از خطر که عمداً کمی از مرکز فاصله دارد. ۱۵٪ امتیاز همان خطر کم می‌شود.
- خطر پیداشده امتیاز می‌گیرد (سختی × ضریب پیاپی)؛ در حالت زمان‌دار کل صحنه ۱۵۰ ثانیه است و سرعت جایزه دارد.
- «پایان و نمایش پاسخ‌ها» دور را ناکامل حساب می‌کند (XP نصف، بدون بونوس).
- ستاره از **دقتِ وزنیِ خطرهای پیداشده** می‌آید؛ بی‌نقص یعنی همه‌ی خطرها، بدون راهنما و بدون لمس اشتباه.

## وضعیت فعلی

`site-01` یک **صحنه‌ی موقت** است: برشی ۶۸۴×۴۱۴ از طرح مرجع (افقی و کم‌وضوح). فقط برای ساخت و آزمودن مکانیک بازی است و **نباید منتشر شود**. متن ده خطر آن هم `draft` است و با تصویر نهایی دوباره نوشته می‌شود.
